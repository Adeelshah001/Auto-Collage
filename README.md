# Auto Collage

Auto Collage is an offline Android app that turns your photos into borderless collages.

- Select and reorder up to 100 photos.
- Use an automatic layout or choose the number of rows.
- Crop or fit photos, with black, white, or transparent backgrounds.
- Preview and resize your collage, then save or share it as a PNG or JPEG.

Requires Android 8.0 or later. Get the APK from [GitHub Releases](https://github.com/Adeelshah001/Auto-Collage/releases).
